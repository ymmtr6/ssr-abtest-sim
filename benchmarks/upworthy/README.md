# Public headline archive

A useful follow-up is to score pairs from the Upworthy Research Archive
(Matias, Munger, Le Quere, and Ebersole, Scientific Data, 2021,
<https://www.nature.com/articles/s41597-021-00934-7>, CC BY 4.0) and compare
the SSR preference with the recorded winner.

This directory does not download that archive and does not include headline
text. `ssr_abtest.calibrate.agreement_rate` is the scoring helper for a
table you prepare yourself: one predicted winner and one label per row.
Ties count as disagreements.

Bring your own API key, your own anchor sets, and a local copy of the
archive if you run that study.
